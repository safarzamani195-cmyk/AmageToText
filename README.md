تبدیل عکس به متن | AmageToText

تبدیل عکس به متن یک برنامه اندرویدی برای استخراج متن از تصاویر است که با هدف فراهم‌کردن یک ابزار ساده، سریع و کاربردی برای کاربران فارسی‌زبان و عربی‌زبان طراحی شده است.

این برنامه به کاربر اجازه می‌دهد یک تصویر را از گالری انتخاب کند یا با دوربین عکس بگیرد و متن موجود در تصویر را به‌صورت خودکار استخراج و ویرایش کند.

امکانات اصلی

- 📷 دریافت تصویر از دوربین
- 🖼️ انتخاب تصویر از گالری
- 🔤 تشخیص متن فارسی و عربی
- ✏️ امکان ویرایش متن استخراج‌شده
- 📋 کپی‌کردن متن
- 💾 ذخیره متن‌های استخراج‌شده
- 🔎 جست‌وجو در متن‌های ذخیره‌شده
- 📤 اشتراک‌گذاری متن
- ⚙️ تنظیم اندازه نوشته و زبان برنامه
- 🌙 پشتیبانی از حالت تاریک
- 🔒 پردازش آفلاین متن، بدون نیاز دائمی به اینترنت

فناوری

این پروژه با Android Studio و Kotlin توسعه داده شده و برای تشخیص متن از موتور Tesseract OCR استفاده می‌کند. مدل‌های زبانی فارسی و عربی نیز برای پردازش متن در برنامه قرار گرفته‌اند.

هدف پروژه

هدف اصلی AmageToText ساخت یک ابزار OCR ساده و قابل‌استفاده برای فارسی و عربی است؛ به‌خصوص برای تبدیل متن موجود در کتاب‌ها، اسناد، تصاویر و نوشته‌های مختلف به متن دیجیتال قابل ویرایش.

این پروژه در حال توسعه است و قابلیت‌های آن می‌تواند در نسخه‌های آینده بهبود و گسترش پیدا کند.
